# LK-09 Pembaruan Business Model Canvas

Hubungkan hasil eksperimen dengan model bisnis. Tulis "belum diuji" apabila belum ada bukti relevan. Tidak semua blok harus berubah.

| Blok BMC | Isi (berdasarkan PRD/SRS) | Status Bukti |
|----------|---------------------------|--------------|
| 1. Customer Segments | Pemilik bengkel, pemilik kendaraan (mobil/motor), mekanik, penggemar DIY | Belum diuji |
| 2. Value Propositions | Diagnosis AI cepat dan akurat, instruksi perbaikan, rekomendasi suku cadang, visualisasi 3D modifikasi | Belum diuji |
| 3. Channels | Platform web (Next.js), link afiliasi Shopee, Maps API | Belum diuji |
| 4. Customer Relationships | Self-service diagnosis, dukungan mekanik, chat AI avatar | Belum diuji |
| 5. Revenue Streams | Komisi afiliasi Shopee dari suku cadang dan komponen | Belum diuji |
| 6. Key Activities | Pengembangan model AI/RAG, rendering 3D, pemeliharaan API dan database | Belum diuji |
| 7. Key Resources | Tim fajar1180 + ilhamalmunawar05-cpu, PostgreSQL + pgvector, LLM OpenAI/Claude, Celery + Redis | Belum diuji |
| 8. Key Partnerships | Shopee Affiliate, Maps API, penyedia LLM | Belum diuji |
| 9. Cost Structure | Biaya API LLM, infrastruktur server, biaya pengembangan tim | Belum diuji |

Catatan: semua blok ditandai "belum diuji" karena belum ada eksperimen atau wawancara calon pengguna yang dilaksanakan. Blok akan diperbarui setelah setiap siklus eksperimen selesai.
