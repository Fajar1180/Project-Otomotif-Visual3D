# LK-07 Log Bukti dan Metrik

Metrik utama (satu) + maksimal dua pendukung. Laporkan jumlah absolut bersama persentase. Likes, kunjungan, dan unduhan saja bukan bukti penggunaan berulang atau pembayaran.

| Metrik | Jenis | Rumus | Sumber Data | Target | Aktual | Status |
|--------|-------|-------|-------------|--------|--------|--------|
| Akurasi diagnosis | Utama | (kasus cocok / total kasus) × 100% | Catatan uji pakai + ground truth mekanik | ≥ 85% | Belum ada data | Belum diuji |
| Latensi API | Pendukung | rata-rata waktu respons / jumlah request | Log API FastAPI | < 200ms | Belum ada data | Belum diuji |
| Konversi ke bengkel | Pendukung | (pengguna yang ke bengkel / total pengguna) × 100% | Wawancara calon pengguna | — | Belum ada data | Belum diuji |

Catatan: 0 entri bukti saat ini. Semua metrik menunggu pelaksanaan eksperimen (LK-03) dan wawancara (LK-04) dengan calon pengguna riil.
