# LK-03 Validation Board

Asumsi paling berisiko yang diuji: **Asumsi 5 (LK-02)** — Akurasi diagnosis >85% dan latensi API <200ms tercapai di produksi.

Diisi rancangan sebelum pengujian; hasil diisi setelah pengujian. Simpan versi sebelumnya.

| Komponen | Isi |
|----------|-----|
| Segmen pelanggan | Pemilik kendaraan dan mekanik bengkel |
| Hipotesis masalah/solusi | Jika sistem diagnosis AI memberikan hasil yang akurat (>85%) dan cepat (<200ms), maka pemilik kendaraan akan menggunakannya sebagai alternatif sebelum datang ke bengkel |
| Asumsi paling berisiko | Akurasi diagnosis dan latensi API memenuhi ambang keberhasilan |
| Metode dan kriteria peserta | Uji pakai terhadap 10 kasus gejala kendaraan dengan diagnosa mekanik ahli sebagai ground truth. Peserta: 2 mekanik bengkel + 3 pemilik kendaraan |
| Jumlah peserta & periode | 10 kasus uji, periode 1 minggu |
| Metrik dan rumus | Akurasi = (jumlah kasus cocok dengan diagnosa ahli / total kasus) × 100%; Latensi = rata-rata waktu respons API / jumlah request |
| Ambang & alasan pemilihan | Akurasi ≥ 85% (min. 9 dari 10 kasus cocok) dan latensi rata-rata < 200ms. Ambang ditetapkan sebelum pengujian, sesuai PRD §8 |
| Hasil aktual | Belum diuji — menunggu pelaksanaan eksperimen dengan calon pengguna riil |
| ID bukti | Belum ada |
| Status hipotesis | Belum konklusif |
| Pembelajaran | Belum ada (belum dilakukan pengujian) |
| Keputusan / hipotesis baru | Belum dapat diambil |
